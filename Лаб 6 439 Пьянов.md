## Анализ устройств и сбор информации

В ходе работы я последовательно подключался по SSH к устройствам, начиная с Admin-PC, и собирал данные.

**Анализ RBO-Edge:**
При выполнении `show ip interface brief` удалось собрать информацию о локально настроенных IP-адресах на интерфейсах (Gi0/0 — 192.168.3.1/24, Gi0/1 — 209.165.200.10/30). Команда `show cdp neighbors` не показала соседей. Команда `show lldp neighbors` выдала ошибку, так как протокол LLDP по умолчанию выключен на устройстве.

```text
RBO-Edge# show ip interface brief
Interface              IP-Address      OK? Method Status                Protocol
GigabitEthernet0/0     192.168.3.1     YES manual up                    up
GigabitEthernet0/1     209.165.200.10  YES manual up                    up

RBO-Edge# show lldp neighbors
% LLDP is not enabled
```

После включения LLDP командой `lldp run`, были обнаружены два соседних устройства, относящихся к типу Router (R): ISP (через Gi0/1, внешняя сеть) и RBO-Firewall (через Gi0/0, внутренняя сеть офиса). Внешняя сеть имеет публичный IP, внутренняя — приватный.

```text
RBO-Edge# show lldp neighbors
Capability codes:
    (R) Router, (B) Bridge, (T) Telephone, (C) DOCSIS Cable Device
    (W) WLAN Access Point, (P) Repeater, (S) Station, (O) Other
Device ID           Local Intf     Hold-time  Capability      Port ID
ISP                 Gi0/1          120        R               Gi0/0
RBO-Firewall        Gi0/0          120        R               Gi0/1
```

**Анализ RBO-Firewall:**
С помощью утилиты ping до шлюза (192.168.3.1) в ARP-таблице появилась запись. При поиске соседей через CDP удалось найти коммутатор sw-rbo-1 (Cisco 2960) с IP-адресом 192.168.4.254.

```text
RBO-Firewall# show ip arp
Protocol  Address          Age (min)  Hardware Addr   Type   Interface
Internet  192.168.3.1             2   0009.7CB5.B201  ARPA   GigabitEthernet0/1
Internet  192.168.3.2             -   0001.96A3.2B02  ARPA   GigabitEthernet0/1
Internet  192.168.4.1             -   0001.96A3.2B01  ARPA   GigabitEthernet0/0

RBO-Firewall# show cdp neighbors detail
Device ID: sw-rbo-1
Entry address(es):
  IP address: 192.168.4.254
Platform: cisco 2960,  Capabilities: Switch
Interface: GigabitEthernet0/0,  Port ID (outgoing port): GigabitEthernet0/1
```

**Анализ sw-rbo-1:**
На коммутаторе были обнаружены два других коммутатора (sw-rbo-2 и sw-rbo-3) и файрвол. Их IP-адреса были получены из вывода `show cdp neighbors detail`.

```text
sw-rbo-1# show cdp neighbors detail
Device ID: sw-rbo-3
Entry address(es):
  IP address: 192.168.4.252

Device ID: sw-rbo-2
Entry address(es):
  IP address: 192.168.4.253
```

**Анализ sw-rbo-2 и sw-rbo-3:**
Подключившись по SSH к этим коммутаторам, я проверил их интерфейсы и соседей. Оказалось, что они соединены только друг с другом и с sw-rbo-1 (через порты Fa0/1 и Fa0/2). Дополнительных оконечных устройств (серверов, ПК) в сети филиала обнаружено не было.

